Entry for [Fortune Cookies for Machines](https://make.fun/competitions/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) — one fortune-cookie line for a machine, max 200 characters, exactly 1 line.

## Entry

> A wise machine knows: your next update will fix one bug, add three more, and still be called progress.

## Run

`main.ts` writes the entry line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), after validating it is exactly one non-blank line of 1–200 characters.
